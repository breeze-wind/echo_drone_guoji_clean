# STM32F103C8T6 三路电磁铁控制操作清单

## 1. 最终功能

一个按钮控制一个状态值：

| 状态值 | 电磁铁1 | 电磁铁2 | 电磁铁3 |
|---|---|---|---|
| 0 | 工作 | 工作 | 工作 |
| 1 | 不工作 | 工作 | 工作 |
| 2 | 不工作 | 不工作 | 工作 |
| 3 | 不工作 | 不工作 | 不工作 |

每按一次按钮，状态值加 1；超过 3 后回到 0。

## 2. 推荐引脚

| 功能 | STM32 引脚 | CubeMX 模式 |
|---|---|---|
| 按钮 | PA0 | GPIO_Input |
| 电磁铁1控制 | PB0 | GPIO_Output |
| 电磁铁2控制 | PB1 | GPIO_Output |
| 电磁铁3控制 | PB10 | GPIO_Output |
| ST-Link 下载 | PA13 / PA14 | Serial Wire |

尽量不要用 PA13、PA14 做普通 IO，这两个脚用于 ST-Link 下载调试。

如果你坚持沿用当前代码里的 PB3、PB4、PB5、PB6，也可以，但 CubeMX 里必须把 `SYS -> Debug` 设置成 `Serial Wire`，不要用完整 JTAG；否则 PB3/PB4 可能被调试功能占用。

## 3. CubeMX 配置

1. 打开 CubeMX，新建工程。
2. 芯片选择 `STM32F103C8Tx`。
3. `SYS -> Debug` 选择 `Serial Wire`。
4. `RCC -> High Speed Clock`：
   - 如果板子上有 8MHz 晶振，选 `Crystal/Ceramic Resonator`。
   - 大多数 STM32F103C8T6 最小系统板都有 8MHz 晶振。
5. `Clock Configuration`：
   - HSE = 8MHz。
   - PLL 倍频 x9。
   - SYSCLK = 72MHz。
6. `PA0` 设置为 `GPIO_Input`：
   - GPIO Pull-up。
   - 按钮一端接 PA0，另一端接 GND。
7. `PB0 / PB1 / PB10` 设置为 `GPIO_Output`：
   - Output Push Pull。
   - Low speed 即可。
   - 如果驱动模块是高电平触发，初始输出电平设为 Low。
   - 如果驱动模块是低电平触发，初始输出电平设为 High。
8. `Project Manager`：
   - Toolchain / IDE 选择 `MDK-ARM`。
   - 生成代码。

## 4. 放入代码

1. CubeMX 生成工程后，用 Keil 打开 `.uvprojx` 工程。
2. 打开 `Core/Src/main.c`。
3. 用本目录里的 `完整代码_main.c` 替换 CubeMX 生成的 `main.c`。
4. 如果 CubeMX 生成的时钟配置和这份代码不同，优先保留 CubeMX 自己生成的 `SystemClock_Config()`。
5. 检查代码顶部这一行：

```c
#define DRIVER_ACTIVE_HIGH         1
```

如果你的驱动模块是：

| 驱动模块类型 | 这一行怎么设 |
|---|---|
| 高电平触发：IN = 高电平时电磁铁工作 | `#define DRIVER_ACTIVE_HIGH 1` |
| 低电平触发：IN = 低电平时电磁铁工作 | `#define DRIVER_ACTIVE_HIGH 0` |

## 5. Keil 烧录设置

ST-Link 和 STM32 接线：

| ST-Link | STM32F103C8T6 |
|---|---|
| 3.3V | 3.3V |
| GND | GND |
| SWDIO | PA13 |
| SWCLK | PA14 |

Keil 设置：

1. 点击魔术棒 `Options for Target`。
2. `Debug` 页选择 `ST-Link Debugger`。
3. 点 `Settings`，Port 选择 `SW`。
4. 编译工程。
5. 点击 `Download` 烧录。

## 6. 元件接线

三路驱动模块输入：

| STM32 | 驱动模块 |
|---|---|
| PB0 | IN1 |
| PB1 | IN2 |
| PB10 | IN3 |
| GND | GND |

电源和负载：

1. 电磁铁使用独立电源，不要从 STM32 的 3.3V 或 5V 引脚给电磁铁供电。
2. 外部电源电压要等于电磁铁额定电压，例如 12V 电磁铁用 12V 电源。
3. STM32 GND、驱动模块 GND、外部电源负极必须共地。
4. 电磁铁接到驱动模块输出端。
5. 如果驱动模块没有续流二极管，每个电磁铁两端并联一个 1N4007：
   - 二极管负极接电磁铁电源正极。
   - 二极管正极接驱动模块输出端。

## 7. 建议测试顺序

1. 先不要接电磁铁，只接 STM32、按钮、ST-Link。
2. 用万用表测 PB0、PB1、PB10 的电平变化。
3. 按钮每按一次，三路输出应按下面规律变化。
4. 再接驱动模块输入，不接电磁铁，确认驱动模块指示灯变化。
5. 最后接外部电源和电磁铁。

高电平触发时，输出电平应为：

| 状态值 | PB0 | PB1 | PB10 |
|---|---|---|---|
| 0 | 高 | 高 | 高 |
| 1 | 低 | 高 | 高 |
| 2 | 低 | 低 | 高 |
| 3 | 低 | 低 | 低 |

低电平触发时，上表高低电平相反。

## 8. 常见问题排查

### 按按钮没有反应

检查 PA0 是否设置成 `GPIO_Input + Pull-up`，按钮是否一端接 PA0、一端接 GND。

### 电磁铁工作逻辑反了

修改 `完整代码_main.c` 顶部：

```c
#define DRIVER_ACTIVE_HIGH 1
```

高电平触发用 1，低电平触发用 0。

### Keil 下载失败

检查：

1. `SYS -> Debug` 是否为 `Serial Wire`。
2. ST-Link 的 SWDIO 是否接 PA13。
3. ST-Link 的 SWCLK 是否接 PA14。
4. GND 是否共地。
5. Keil Debug 设置里 Port 是否为 `SW`。

### 电磁铁吸合时 STM32 重启

通常是电源或干扰问题：

1. 电磁铁必须用独立电源。
2. STM32 和驱动模块要共地。
3. 电磁铁两端加续流二极管。
4. 外部电源电流要足够。
5. 电磁铁电源线和 STM32 信号线尽量分开。

## 9. 最小验收标准

完成后，至少确认下面几项：

- [ ] CubeMX 里 PA0 是输入上拉。
- [ ] CubeMX 里 PB0、PB1、PB10 是推挽输出。
- [ ] Keil 能编译通过。
- [ ] ST-Link 能下载成功。
- [ ] 按钮每按一次只改变一次状态。
- [ ] 状态 0 时三个电磁铁都工作。
- [ ] 状态 3 时三个电磁铁都不工作。
- [ ] 电磁铁工作时 STM32 不重启。
- [ ] 驱动模块和 STM32 已共地。
- [ ] 电磁铁没有从 STM32 板子取电。
