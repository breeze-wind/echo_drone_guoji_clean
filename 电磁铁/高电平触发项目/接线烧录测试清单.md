# 接线、烧录、测试清单

## 1. 需要的东西

- STM32F103C8T6 最小系统板
- ST-Link 下载器
- 3 个 N-MOSFET 电磁铁驱动模块
- 3 个电磁铁
- 1 个按钮
- 电磁铁对应电压的外部电源，例如 12V 电磁铁用 12V 电源
- 若模块没有续流二极管，准备 3 个 `1N4007` 或类似二极管
- 杜邦线若干

## 2. ST-Link 烧录接线

| ST-Link | STM32F103C8T6 |
|---|---|
| 3.3V | 3.3V |
| GND | GND |
| SWDIO | PA13 |
| SWCLK | PA14 |

注意：不要把 ST-Link 的 5V 接到 STM32 的 3.3V。

## 3. 按钮接线

| 按钮 | STM32 |
|---|---|
| 一端 | PA0 |
| 另一端 | GND |

CubeMX 里 PA0 已经设置为内部上拉，所以不需要外接上拉电阻。

## 4. MOSFET 驱动模块输入接线

| STM32 | MOSFET 模块 |
|---|---|
| PB0 | IN1 或第 1 路 IN |
| PB1 | IN2 或第 2 路 IN |
| PB10 | IN3 或第 3 路 IN |
| GND | GND |

如果你是 3 个单路 MOSFET 模块，就分别接 3 个模块的 IN。

## 5. 电磁铁供电和输出接线

典型 N-MOSFET 低端开关接法：

| 连接点 | 接到哪里 |
|---|---|
| 外部电源正极 | 电磁铁正极 |
| 电磁铁负极 | MOSFET 模块输出端，例如 OUT- / LOAD- |
| MOSFET 模块 GND | 外部电源负极 |
| STM32 GND | 外部电源负极 / MOSFET GND |

最关键的一句：

```text
STM32 GND、MOSFET 模块 GND、外部电源负极必须接在一起。
```

不要用 STM32 板子的 3.3V 或 5V 给电磁铁供电。

## 6. 续流二极管

电磁铁是感性负载，断电时会产生反向电压。

如果你的 MOSFET 模块上已经有续流二极管，可以不用另加。

如果没有，每个电磁铁两端并联一个二极管：

| 二极管端 | 接到哪里 |
|---|---|
| 有白/银色横线的一端，负极 | 电磁铁正极 / 外部电源正极 |
| 没有横线的一端，正极 | 电磁铁负极 / MOSFET 输出端 |

## 7. Keil 烧录步骤

1. 用 Keil 打开 CubeMX 生成的 `.uvprojx` 工程。
2. 点击魔术棒 `Options for Target`。
3. 进入 `Debug`。
4. 选择 `ST-Link Debugger`。
5. 点击 `Settings`。
6. `Port` 选择 `SW`。
7. 编译工程。
8. 点击 `Download` 烧录。

## 8. 建议测试顺序

### 第一步：只测 STM32 输出

先不接电磁铁，只接 STM32、按钮、ST-Link。

用万用表测：

| 状态 | PB0 | PB1 | PB10 |
|---|---|---|---|
| 0 | 高 | 高 | 高 |
| 1 | 低 | 高 | 高 |
| 2 | 低 | 低 | 高 |
| 3 | 低 | 低 | 低 |

每按一次按钮，状态往下一行变化；状态 3 再按一次回到状态 0。

### 第二步：接 MOSFET 模块，不接电磁铁

看 MOSFET 模块指示灯是否按上表变化。

### 第三步：接电磁铁

确认外部电源电压正确、GND 共地、续流保护正确后，再接电磁铁。

## 9. 最终验收清单

- [ ] CubeMX 芯片是 `STM32F103C8Tx`
- [ ] `SYS -> Debug` 是 `Serial Wire`
- [ ] `PA0` 是 `GPIO_Input + Pull-up`
- [ ] `PB0 / PB1 / PB10` 是 `GPIO_Output`
- [ ] Keil 可以编译通过
- [ ] ST-Link 可以下载成功
- [ ] STM32、MOSFET 模块、外部电源负极已经共地
- [ ] 电磁铁没有从 STM32 板子取电
- [ ] 状态 0 时三个电磁铁都工作
- [ ] 状态 1 时第一个不工作，后两个工作
- [ ] 状态 2 时前两个不工作，第三个工作
- [ ] 状态 3 时三个都不工作
- [ ] 电磁铁吸合或释放时 STM32 不重启

## 10. 如果出现问题

### 按钮没反应

检查 PA0 是否真的设置为 `Pull-up`，按钮是否一端接 PA0、一端接 GND。

### 电磁铁一直工作

检查 MOSFET 模块 IN 是否悬空，STM32 GND 是否和 MOSFET GND 共地。

### 电磁铁完全不工作

检查外部电源电压、电源电流、MOSFET 模块接线方向、电磁铁正负接法。

### STM32 一吸合就重启

通常是电源干扰或反向电压：

- 电磁铁必须用独立电源
- 必须共地
- 加续流二极管
- 外部电源电流要够
- 电磁铁电源线和 STM32 信号线尽量分开走
