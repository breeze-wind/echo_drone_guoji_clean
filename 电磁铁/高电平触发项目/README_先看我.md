# 高电平触发版项目说明

这个文件夹是按你的硬件重新整理的版本：

- 单片机：STM32F103C8T6 最小系统板
- 驱动模块：N-MOSFET，高电平触发
- 电磁铁数量：3 个
- 控制方式：一个按钮循环改变状态值

## 文件说明

| 文件 | 用途 |
|---|---|
| `main.c` | 完整主程序，复制到 CubeMX 生成工程的 `Core/Src/main.c` |
| `CubeMX配置清单.md` | 告诉你 CubeMX 每个引脚怎么配 |
| `接线烧录测试清单.md` | 告诉你 ST-Link、按钮、驱动模块、电磁铁怎么接 |
| `引脚表.csv` | 简短引脚表，方便打印或对照 |
| `状态输出表.csv` | 每个状态对应的输出电平 |

## 最重要的结论

N-MOSFET 高电平触发时：

| STM32 输出 | 电磁铁 |
|---|---|
| 高电平 | 工作 |
| 低电平 | 不工作 |

所以本项目代码已经固定为：

```c
#define APP_MAGNET_WORK_LEVEL      GPIO_PIN_SET
#define APP_MAGNET_STOP_LEVEL      GPIO_PIN_RESET
```

你不需要再判断高低电平触发，也不需要改这个地方。

## 使用顺序

1. 按 `CubeMX配置清单.md` 新建并配置 CubeMX 工程。
2. 生成 `MDK-ARM / Keil5` 工程。
3. 用本文件夹里的 `main.c` 替换生成工程里的 `Core/Src/main.c`。
4. 在 Keil 里编译。
5. 连接 ST-Link 后下载。
6. 按 `接线烧录测试清单.md` 接线和测试。

建议先用万用表或驱动模块指示灯测试输出，不要一开始就接电磁铁。
